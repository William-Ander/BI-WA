# Regra - Campos removíveis na visualização

A tela Relatórios / Dashboards deve permitir remover campos já adicionados ao visual.

Regras obrigatórias:

- O campo de Eixo / dimensão deve ter botão de remover.
- O campo de Valores deve ter botão de remover.
- O campo de Filtros deve ter botão de remover.
- Remover um campo deve limpar a seleção correspondente.
- Remover um filtro também deve limpar o valor digitado do filtro.
- Depois de remover, o visual deve atualizar automaticamente, sem botão manual.
- Os checkboxes no painel Dados devem refletir somente os campos em uso no visual.
- Nenhuma atualização futura pode voltar a prender campos antigos sem opção de remoção.

Criado em: v2.9.0.
