# Regra - Popup de filtros funcionais

A tela de configuração de filtros deve funcionar como segmentação do Power BI:

- O administrador pode escolher qualquer tabela, view ou tabela nativa como fonte do filtro.
- O visual de filtro dentro do popup deve ser redimensionável.
- O filtro deve renderizar controles reais: suspenso, lista, entre, hoje e pesquisa.
- Na versão online, o botão Filtros deve abrir o popup e aplicar os filtros nos dashboards.
- Não pode ser apenas um cartão informativo; precisa alterar a consulta/renderização do visual.
- Os filtros permitidos devem ser validados no backend antes de serem aplicados.
