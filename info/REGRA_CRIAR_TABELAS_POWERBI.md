# Regra - Criar Tabelas estilo Power BI

A seção **Criar Tabelas** deve funcionar como o recurso **Inserir dados** do Power BI.

Regras permanentes:

- A tela deve ter uma grade editável para digitar dados manualmente.
- Deve permitir colar dados copiados do Excel.
- Deve permitir usar a primeira linha colada como cabeçalho.
- Deve permitir renomear colunas e definir tipos antes de carregar a tabela.
- Deve permitir criar uma tabela manual do BI WA sem alterar tabelas/views externas do MySQL.
- Deve oferecer ID automático para edição segura de linhas manuais.
- A tela **Tabelas e Views** permanece somente visualização; criação e edição estrutural ficam em **Criar Tabelas**.
- Tabelas externas, views, Calendario nativo e consultas transformadas continuam somente leitura.
