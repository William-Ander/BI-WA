# Regra permanente - Editor de dashboards estilo Power BI

Versão registrada: v2.8.2

Esta regra deve ser respeitada em todas as próximas atualizações do BI WA.

## Regras obrigatórias

1. A tela de criação/edição de relatórios deve manter uma página/canvas fixo, padrão 1280x720, para que a publicação online preserve exatamente o mesmo enquadramento.
2. Os visuais dentro da página devem ser posicionáveis por arrastar e redimensionáveis, como no Power BI.
3. Tabelas, matrizes e visuais com muitos dados devem ter rolagem interna dentro do próprio visual. O visual não pode aumentar sozinho a página ou mudar o tamanho do canvas.
4. Painéis laterais, como Visualizações e Dados, devem ter botões funcionais de retrair/expandir.
5. O painel Dados deve permitir arrastar campos para o canvas.
6. A versão online deve renderizar os visuais dentro do mesmo limite/quadrado salvo no desktop.
7. Sempre que o editor for alterado, testar a navegação, os botões de retrair, arrastar campos e rolagem interna antes de gerar ZIP.
