# Regra - Filtros dinâmicos estilo Power BI

A tela de configuração de filtros online deve funcionar como um editor visual:

- O visual de filtro deve ser clicável para edição.
- Deve ser possível excluir qualquer filtro pelo botão X.
- Deve ser possível redimensionar o filtro e preservar largura/altura.
- Suspenso deve carregar valores reais da fonte escolhida.
- Lista deve permitir múltiplas seleções.
- Pesquisa deve permitir digitar texto.
- Entre deve usar dois campos, preferencialmente date para campos de data e number para campos numéricos.
- Hoje deve preencher a data atual.
- Na versão online, o botão Filtros deve abrir o popup e aplicar os filtros ao dashboard imediatamente após clicar em aplicar.
- O backend deve validar que o usuário online só usa filtros liberados pelo administrador.

Esta regra deve ser mantida em todas as próximas versões.
