# Regra permanente - Painéis recolhíveis

Todos os painéis laterais do BI WA devem ser recolhíveis sem desaparecer.

Regras:

- Painel recolhido deve deixar uma aba/trilho visível para expandir novamente.
- Na tela Conexões, os painéis auxiliares devem ficar no lado direito/final da página.
- O painel principal/canvas deve ganhar espaço quando painéis auxiliares forem recolhidos.
- Cards de tabelas/views salvos no modelo visual devem permanecer ao sair e voltar da tela.
- Relacionamentos salvos devem continuar desenhados entre as colunas dos cards.
- Nenhuma atualização futura pode voltar a usar largura 0 ou `display:none` sem manter botão visível de retorno.
