# v3.2.78 - Cache Local Incremental

- Implementa atualização incremental do cache SQLite local.
- Detecta coluna de sincronização por prioridade: `updated_at`, `data_alteracao`, `ultima_atualizacao`, `id`, `auto_increment` ou data de movimento.
- Preserva sincronização completa como fallback seguro.
- Adiciona metadados `sync_strategy`, `sync_column` e `primary_keys` ao cache local.
- Adiciona botão para atualização incremental e botão separado para recarga completa.
- Não altera banco MySQL real nem regras de Tabela/Matriz.
