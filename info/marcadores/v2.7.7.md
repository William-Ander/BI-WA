# v2.7.7 - Correção da listagem de tabelas e views

## Ajustes
- Corrigida a tela que podia ficar presa em **Carregando...** quando a API de tabelas/views falhava.
- Adicionado tratamento visual de erro no menu lateral com botão para tentar novamente.
- Melhorada a busca de tabelas e views no MySQL com diagnóstico dos métodos usados.
- Adicionado endpoint interno de diagnóstico `/api/tables/debug`.
- Mantida a regra: tabelas/views do MySQL são somente leitura; apenas tabelas manuais criadas pelo BI WA são editáveis.

## Observação
Se nenhuma view aparecer mesmo após esta versão, valide no MySQL se o usuário possui permissão `SHOW VIEW` e `SELECT` nas views.
