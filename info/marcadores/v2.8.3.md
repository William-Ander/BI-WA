# BI WA v2.8.3

## Ajustes

- Corrigido erro `Nome inválido para SQL` ao usar colunas com espaços, acentos ou caracteres especiais, como `Descrição Comercial`.
- Gerador visual agora usa crase e escape seguro para identificadores MySQL.
- Backend também aceita identificadores MySQL com espaços/acentos quando protegidos por crase.
- Painel **Dados** compactado para mostrar melhor colunas de tabelas grandes, como `faturamento2`.
- Tabelas/matrizes no canvas mantêm rolagem interna e colunas mais compactas.

## Regra permanente

O BI WA deve aceitar nomes reais vindos do MySQL, incluindo espaços e acentos. Não voltar a restringir nomes de colunas/tabelas para apenas letras, números e underscore no gerador visual.
