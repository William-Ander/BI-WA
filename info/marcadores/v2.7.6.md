# BI WA v2.7.6

## Marcador de versão

Atualização criada para adicionar modelagem de relatórios no estilo Power BI.

## Itens adicionados

- Aba `Modelo / Medidas`.
- Seleção visual de colunas de tabelas e views.
- Cadastro de relacionamentos entre tabelas/views.
- Criação de medidas DAX simples.
- Geração de SQL seguro a partir do modelo.
- Prévia do relatório criado pelo modelo.

## Regra preservada

Tabelas e views vindas do MySQL externo são somente leitura. Somente tabelas manuais criadas pelo BI WA podem ser editadas.
