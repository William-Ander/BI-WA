# v3.1.0 - Visualização de tabelas paginada

## Ajustes
- Remove timeout curto de 5 segundos da visualização de tabelas grandes.
- A tela Tabelas e Views carrega uma amostra paginada, iniciando com 50 linhas.
- A consulta de linhas não executa COUNT(*) pesado por padrão.
- Adiciona botões Anterior/Próxima para navegar pelas linhas.
- Mantém Calendario como fonte nativa/virtual.

## Regra
A visualização de tabelas grandes nunca deve depender de COUNT(*) ou timeout curto. Sempre carregar uma página pequena primeiro e permitir navegação paginada.
