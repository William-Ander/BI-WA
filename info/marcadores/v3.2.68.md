# BI WA v3.2.68 - Cross-filter visual com seleção múltipla

Data: 2026-06-02

## Alterações

- Cross-filter agora aceita seleção múltipla por campo.
- Chips de seleção mostram resumo e quantidade total de valores ativos.
- Tabelas destacam células selecionadas.
- Gráficos HTML destacam barras e fatias selecionadas.
- Gráficos ECharts recebem estado de seleção quando há valores ativos.
- Backend normaliza listas de valores e aplica `IN (...)` seguro para múltipla seleção.

## Regras preservadas

- Não altera banco de dados real.
- Não salva cross-filter no SQL do relatório.
- Não transforma texto em agregação.
- Não gera `SUM(Cliente)` nem `SUM(Descrição Comercial)`.
- Filtros continuam apenas adicionando `WHERE`.
