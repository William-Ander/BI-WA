# v3.0.4 - Calendario nativo virtual corrigido

Data: 2026-05-30

## Ajustes

- Corrigida a rota `/api/tables/Calendario/rows` para retornar dados virtuais antes de verificar existência no MySQL.
- Corrigido o criador visual para não gerar `FROM Calendario` físico quando a fonte é nativa.
- Mantida a regra: Calendario é fonte nativa/virtual, somente leitura e não depende de permissão `CREATE` no MySQL.

## Regra permanente

A fonte `Calendario` nunca deve ser consultada, criada, alterada ou validada como tabela física do MySQL. Ela deve ser resolvida pelo BI WA como fonte nativa/virtual.
