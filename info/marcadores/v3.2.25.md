# BI WA v3.2.25

## Etapa 3 - Canvas central Power BI

- Melhoria visual do canvas central do editor de relatórios.
- Grade refinada com linhas menores e marcações maiores.
- Régua visual superior/lateral para orientar posicionamento.
- Seleção do visual com contorno, destaque e etiqueta de tamanho.
- Novos comandos rápidos no editor:
  - Alinhar à esquerda;
  - Alinhar ao topo;
  - Centralizar na página;
  - Trazer para frente;
  - Duplicar visual.
- Atalhos de teclado no canvas:
  - Setas: mover visual selecionado;
  - Shift + setas: mover mais rápido;
  - Alt + setas: redimensionar;
  - Ctrl+D: duplicar visual.
- Preservação de camada visual via `zIndex` dentro do layout do visual.
- ZIP mantido limpo, sem `.env` real, `node_modules`, logs, perfil local ou credenciais reais.
