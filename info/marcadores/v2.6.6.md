# BI WA v2.6.6

## Tipo
Correcao de instalador

## Ajuste
- Corrigida a limpeza do cache de icones do Windows no instalador.
- O instalador agora usa `Join-Path -Path ... -ChildPath ...` de forma segura.
- Se o Windows bloquear os arquivos de cache, o instalador ignora sem interromper a instalacao.
- Mantida a recriacao do atalho BI WA com o icone dedicado da barra de tarefas.

## Motivo
Evitar o erro: `Nao e possivel converter System.Object[] para System.String necessario para o parametro ChildPath`.
