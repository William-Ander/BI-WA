# BI WA v3.0.1

## Transformar Dados - colunas personalizadas e condicionais

Esta versão adiciona ao módulo **Transformar Dados**:

- Etapa **Coluna personalizada**.
- Etapa **Coluna condicional**.
- Prévia recalculada automaticamente com as novas colunas.
- Expressões com colunas usando `[Nome da Coluna]`.
- Registro da regra no arquivo `info/REGRA_TRANSFORMAR_DADOS_POWERQUERY.md`.
