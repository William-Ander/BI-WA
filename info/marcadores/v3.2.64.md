# BI WA v3.2.64 - Modelagem semântica reforçada

## O que mudou

- Preserva medidas importadas do PBIX mesmo quando a fórmula DAX não foi extraída.
- Aumenta o limite interno de medidas, relacionamentos e colunas selecionadas do modelo.
- Adiciona diagnóstico do modelo semântico com contagem de tabelas, medidas, visuais, filtros e SQLs placeholder.
- Adiciona endpoint e botão de auto relacionamento por colunas equivalentes, útil para aproximar o comportamento de filtros do Power BI.
- Melhora a geração SQL do modelo para montar JOINs em múltiplas passagens e avisar quando uma tabela não está ligada ao modelo principal.
- Mantém a regra congelada de Tabela/Matriz: campo textual vira coluna direta, nunca `SUM(texto)`, e filtros não mudam a estrutura da tabela.

## Observação

Medidas PBIX sem fórmula ficam visíveis como pendentes. Elas são preservadas para mapeamento, mas só entram na geração SQL quando receberem uma fórmula compatível.
