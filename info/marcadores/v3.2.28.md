# BI WA v3.2.28 - Login, usuários e permissões do Online

## O que mudou

- Adicionada tela de login própria ao abrir o BI WA Online.
- Adicionado endpoint de autenticação `/api/auth/login` com token de sessão.
- Removida dependência da janela nativa de Basic Auth para o uso normal do Online.
- Adicionado cadastro de usuários online dentro da aba Configuração.
- Adicionada configuração de permissões por relatório e por página.
- A API `/api/reports` passa a devolver, no modo online, somente os relatórios liberados ao usuário autenticado.
- A execução/exportação de relatórios no Online valida permissão antes de retornar dados.
- O WebSocket do dashboard também passa a autenticar usando o token da tela de login.

## Segurança

- A versão online continua somente leitura quando `APP_MODE=online`.
- Usuários sem permissão não recebem metadados nem dados dos relatórios bloqueados.
- O pacote final não deve incluir `.env`, `node_modules`, logs, perfil local ou credenciais reais.
