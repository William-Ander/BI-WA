# BI WA v3.0.0

## Transformar Dados - Mesclar/acrescentar consultas

Esta versão adiciona ao módulo Transformar Dados as funções estilo Power Query:

- Mesclar consultas;
- Acrescentar consultas;
- Prévia automática das novas etapas;
- Geração de SQL seguro sem alterar o MySQL original.

## Regra

As transformações de Power Query do BI WA devem continuar sendo uma camada sem alteração da base original. Mesclar e acrescentar consultas devem funcionar sobre tabelas, views e consultas transformadas salvas.
