# v2.9.6 - Calendário nativo virtual nos filtros

Data: 2026-05-29

## Correção

Corrigido erro ao usar a tabela nativa `Calendario` no popup de filtros quando o usuário MySQL não possui permissão `CREATE`.

## Regra registrada

A tabela `Calendario` deve ser tratada como nativa/virtual pelo BI WA para filtros e modelagem, sem exigir criação de tabela física no MySQL.
