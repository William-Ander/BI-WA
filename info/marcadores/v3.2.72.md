# BI WA v3.2.72 - Power Query ampliado

Esta versão amplia a tela **Transformar Dados** com etapas seguras inspiradas no Power Query:

- Preencher vazios;
- Duplicar coluna;
- Dividir coluna por delimitador;
- Formatar texto;
- Agrupar por com agregações seguras.

Também adiciona o endpoint administrativo `/api/transforms/diagnostics` para validar consultas transformadas salvas.

As transformações continuam sendo camada de consulta somente leitura. O banco MySQL original não é alterado.

Regra congelada preservada: Tabela/Matriz não soma texto; filtros apenas adicionam `WHERE`.
