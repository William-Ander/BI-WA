# v2.7.3 - Tabelas manuais editáveis

Data: 2026-05-29

## Alterações

- Tabelas e views vindas do MySQL externo ficam somente leitura.
- Tabelas criadas manualmente pelo BI WA passam a ser registradas em `data/manual_tables.json`.
- Somente essas tabelas manuais podem ser editadas pelo app.
- A interface diferencia recursos como `mysql leitura`, `view` e `manual/editável`.

## Regra permanente

Não permitir escrita direta em tabelas existentes do MySQL externo. Toda edição de dados pelo BI WA deve ocorrer somente em tabelas manuais criadas pelo app.
