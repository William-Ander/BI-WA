# v2.7.1

## Tipo
Correção de estabilidade.

## Alterações
- Servidor local do BI WA agora é validado pelo endpoint `/api/local/ping`.
- Inicializador do app garante que o servidor local esteja rodando antes de abrir a janela.
- Teste de MySQL passa a mostrar erro de backend offline de forma mais clara.
- Mantido ícone oficial do BI WA.

## Observação
Se aparecer erro de MySQL após esta correção, o erro será de conexão MySQL real, como firewall, porta, usuário, senha, base ou SSL.
