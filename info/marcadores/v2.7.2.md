# v2.7.2 - Views do MySQL

Data: 2026-05-29

## Alteracoes

- Adicionado suporte para views na listagem lateral do app.
- Endpoint `/api/tables` agora retorna também `resources`, com tipo `table` ou `view`.
- Views podem ser consultadas em modo leitura.
- Operações destrutivas ou de edição permanecem bloqueadas para views.

## Regra mantida

- Tabelas base podem ser editadas conforme permissões configuradas.
- Views são somente leitura dentro do BI WA.
