# v3.2.6 - Correção de salvamento de conexões

Esta versão corrige o erro exibido ao salvar conexões/modelo quando a validação das tabelas/colunas no MySQL demora mais que o timeout padrão da tela.

## Alterações

- Timeout dedicado de 60 segundos para salvar o modelo sem abortar cedo demais.
- Botão Salvar conexões entra em estado `Salvando...` durante a operação.
- Mensagem de erro diferencia operação demorada de falha real no servidor local.
- Pacote continua limpo, sem `.env`, `node_modules`, logs ou perfil local.
