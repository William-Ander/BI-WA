# v2.7.5 - Marcador de versão corrigido

Data: 2026-05-29

## Alterações
- O marcador de versão do menu lateral agora usa a versão recebida do backend do BI WA.
- O backend lê a versão do `package.json` como fonte oficial.
- O launcher `abrir_bi_wa_app.bat` verifica se o servidor local em execução está na mesma versão instalada.
- Se houver servidor antigo rodando na porta local, ele é encerrado e o servidor da pasta atual é iniciado.
- Arquivos estáticos passam a usar cabeçalhos para reduzir cache de `index.html`, `app.js` e demais assets do app.
- O instalador também encerra servidor antigo na porta local antes de iniciar a versão atual.

## Motivo
O usuário informou que o marcador dentro do app não mudava após atualização. A causa provável era o servidor Node antigo ainda rodando na porta 3000 ou cache de navegador/app em modo janela.
