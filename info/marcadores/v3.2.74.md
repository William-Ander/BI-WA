# v3.2.74 - Validador de Relacionamentos do Modelo

## Objetivo
Fortalecer a camada de relacionamentos do modelo semântico para aproximar o comportamento de filtros/cross-filter do Power BI.

## Alterações
- Novo endpoint `/api/model/relationships/diagnostics`.
- Novo endpoint `/api/model/relationships/suggestions`.
- Nova interface **Diagnóstico rel.** em Modelo / Medidas.
- Nova interface **Sugerir rel.** com confiança alta, média e baixa.
- Relacionamentos agora preservam `active` e `confidence`.
- Relacionamentos inativos são ignorados por geração SQL e propagação de filtros.
- Lista de relacionamentos permite pausar/ativar e alternar direção simples/ambos antes de salvar.
- Diagnóstico aponta duplicidades, tabelas/colunas ausentes, tipos incompatíveis, baixa confiança e tabelas desconectadas.

## Regras preservadas
- Não altera banco/configurações reais.
- Não altera SQL salvo dos relatórios.
- Não transforma texto em `SUM()`.
- Não gera `SUM(Cliente)` nem `SUM(Descrição Comercial)`.
- Filtros continuam como camada de consulta/WHERE.
