# BI WA v2.7.9

## Tipo
Melhoria de interface e carregamento de dados.

## Alterações
- Tela de relatórios/dashboards redesenhada em formato parecido com Power BI.
- Canvas central de relatório.
- Painel Visualizações à direita.
- Painel Dados com tabelas/views e campos.
- Correção para tabelas/views não sumirem quando o modelo semântico falhar.

## Regras mantidas
- Tabelas e views externas do MySQL continuam somente leitura.
- Tabelas manuais criadas pelo BI WA continuam sendo as únicas editáveis.
- SQL continua disponível apenas como modo avançado.
