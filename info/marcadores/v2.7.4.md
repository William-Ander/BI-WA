# BI WA v2.7.4

Data: 2026-05-29

## Upgrade

- Corrigida a busca de views do MySQL.
- O app agora consulta `INFORMATION_SCHEMA.TABLES`, `INFORMATION_SCHEMA.VIEWS` e `SHOW FULL TABLES` para localizar tabelas e views.
- O menu lateral separa objetos em **Tabelas** e **Views**.
- Tabelas externas do MySQL e views continuam somente leitura.
- Tabelas criadas manualmente pelo BI WA continuam editaveis.

## Observacao

Se o usuario MySQL nao tiver permissao para enxergar uma view, ela tambem nao aparecera no BI WA. Nesse caso, liberar permissao `SHOW VIEW`/`SELECT` para o usuario conectado.
