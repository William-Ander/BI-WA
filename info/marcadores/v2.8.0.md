# v2.8.0

## Resumo
Interface compacta, responsiva, janela maximizada e painel de visualizações ampliado no estilo Power BI.

## Alterações
- App passa a abrir maximizado pelo atalho Windows.
- Layout geral reduz espaçamentos, tamanhos e largura da lateral para aproveitar melhor a tela.
- Configuração fica mais compacta para evitar rolagem excessiva.
- Relatórios / Dashboards passa a ter painel de visuais com mais opções no estilo Power BI.
- Adicionados tipos de visual compatíveis: tabela, matriz, barras, colunas, linhas, área, pizza, rosca, dispersão, funil, gauge, cartão, KPI, mapa e segmentação.

## Observação
O BI WA não é uma cópia do Power BI. A interface foi aproximada para facilitar o uso, mantendo implementação própria e segura em Node.js/JavaScript.
