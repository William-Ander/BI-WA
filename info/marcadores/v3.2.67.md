# BI WA v3.2.67 - Cross-filter por relacionamentos

## Objetivo
Aproximar o comportamento do dashboard ao Power BI propagando cross-filter entre visuais de tabelas diferentes quando existe caminho no modelo semantico.

## Melhorias
- Adicionado resolvedor de caminho de relacionamento com busca limitada a 3 saltos.
- Filtros temporarios agora podem ser aplicados por coluna direta, Calendario ou atributos de dimensao relacionados.
- Para atributos de dimensao, o backend monta `EXISTS` com JOINs seguros usando o modelo semantico.
- O filtro continua sendo apenas de execucao; nao altera SQL salvo, relatorio, banco ou transformacoes.

## Regras preservadas
- Tabela/Matriz continua exibindo texto como coluna direta.
- Nunca gerar `SUM(Cliente)`, `SUM(Descricao Comercial)` ou agregacao indevida de texto.
- Filtros podem adicionar `WHERE`, sem mudar a estrutura da tabela/matriz.
- Nao incluir banco real, `.env`, `settings.json`, cache, backup ou credenciais no ZIP limpo.
