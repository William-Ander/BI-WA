# BI WA v2.6.4

## Tipo
Melhoria de interface / acompanhamento de atualizacao.

## Alteracoes

- Adicionado campo **Ultima atualizacao** ao lado do botao **Atualizar agora** no dashboard.
- O campo informa ao usuario o ultimo horario em que os dados foram atualizados.
- Durante atualizacao manual, o campo mostra **atualizando...**.
- Atualizacao automatica via WebSocket tambem atualiza o indicador.

## Arquivos principais alterados

- `public/index.html`
- `public/styles.css`
- `public/app.js`
- `package.json`
- `info/VERSION.json`
- `info/UPGRADES.md`
