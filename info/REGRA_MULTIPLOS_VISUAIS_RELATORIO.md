# Regra - múltiplos visuais no relatório

A tela Relatórios / Dashboards deve permitir mais de um visual no mesmo canvas, como no Power BI.

Regras obrigatórias:
- O usuário deve conseguir criar novo visual pelo botão + Visual ou arrastando um tipo de visual para o canvas.
- Cada visual deve ter posição e tamanho próprios.
- Cada visual deve poder ser selecionado, arrastado, redimensionado e removido.
- O visual selecionado é o que recebe campos, tipo de gráfico, agregação e filtros.
- O relatório salvo deve preservar o layout dos visuais para publicação online.
- Tabelas/matrizes continuam com rolagem interna, sem aumentar o tamanho do visual.
