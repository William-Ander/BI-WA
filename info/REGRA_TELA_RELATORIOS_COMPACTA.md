# Regra - Tela Relatórios/Dashboards compacta

A tela Relatórios/Dashboards deve seguir o padrão de edição do Power BI:

- A página geral do relatório não deve ter rolagem vertical própria.
- O canvas de edição deve ficar em área fixa e compacta.
- A página do relatório deve manter tamanho padrão 1280x720 para garantir publicação online no mesmo enquadramento.
- A rolagem deve existir apenas no menu principal, no painel Visualizações e no painel Dados.
- Tabelas, matrizes e listas dentro de um visual devem ter rolagem interna, sem aumentar o tamanho do visual.
- Botões laterais de recolher/expandir devem continuar funcionando.
- Ao atualizar a interface, não reintroduzir rolagem geral na tela de criação de relatórios.
