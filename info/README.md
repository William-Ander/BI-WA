# Info do BI WA

Esta pasta guarda as informações de versão, upgrades e regras de atualização do app.

## Arquivos principais

- `VERSION.json`: versão atual do app.
- `UPGRADES.md`: histórico consolidado de upgrades.
- `REGRAS_DE_ATUALIZACAO.md`: checklist obrigatório para próximas alterações.
- `marcadores/`: um arquivo por versão entregue.
- `templates/MARCADOR_VERSAO_TEMPLATE.md`: modelo para próximos marcadores.

## Regra principal

Toda vez que o app for atualizado, deve ser criado um novo marcador em `info/marcadores/` e o arquivo `info/VERSION.json` deve ser atualizado com a nova versão.
